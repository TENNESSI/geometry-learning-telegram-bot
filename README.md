# Telegram-бот для обучения геометрии

Учебная система в формате Telegram-бота с отдельными сценариями для учеников и преподавателей.

Проект разработан на заказ для дипломной работы студентки педагогического направления. Заказчик подготовил учебные материалы и задания, а я спроектировал и реализовал программную часть системы.

## Возможности

### Для ученика

- изучение теоретических материалов;
- выбор темы для обучения;
- решение практических заданий;
- прохождение смешанной тренировки;
- получение индивидуальных заданий от преподавателя;
- отправка решений текстом, фотографией или документом;
- просмотр результатов и статистики.

### Для преподавателя

- просмотр списка учеников;
- создание индивидуальных заданий;
- отправка заданий выбранному ученику;
- просмотр полученных решений;
- проверка и оценивание работ;
- просмотр статистики учеников.

## Роли и доступ

В системе предусмотрены две роли:

- **ученик** — изучает материалы и выполняет задания;
- **преподаватель** — назначает задания, проверяет решения и просматривает статистику.

Список преподавателей задаётся через переменную окружения `TEACHER_IDS`.

## Настройка

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=telegram_bot_token
TEACHER_IDS=123456789,987654321
```

Где:

- `BOT_TOKEN` — токен Telegram-бота, полученный у `@BotFather`;
- `TEACHER_IDS` — Telegram ID преподавателей, перечисленные через запятую.

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/TENNESSI/tg-learn-fintiflush.git
cd tg-learn-fintiflush
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте окружение в Linux или macOS:

```bash
source .venv/bin/activate
```

В Windows:

```powershell
.venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите бота:

```bash
python main.py
```

При первом запуске приложение создаст локальную базу данных SQLite.

## Особенности реализации

- обработчики разделены по функциональным модулям;
- взаимодействие с Telegram реализовано асинхронно;
- роли преподавателей настраиваются через переменные окружения;
- пользователи, задания и результаты сохраняются в SQLite;
- реализован полный цикл индивидуального задания:
  **создание → отправка ученику → получение решения → проверка преподавателем**;
- решения можно отправлять текстом, изображением или документом;
- преподаватель может работать с несколькими учениками и отслеживать их результаты.
